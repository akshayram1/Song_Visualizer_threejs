# Music Visualizer

This project is a music visualizer that creates a dynamic and engaging visual experience synchronized with your favorite music.

## Getting Started

Follow these simple steps to get the project up and running on your local machine.

### Prerequisites

Make sure you have Node.js and npm installed on your system. If not, download them from [nodejs.org](https://nodejs.org/).

### Installation

1.  Clone the repository to your local machine.
2.  Navigate to the project directory in your terminal.
3.  Install the project dependencies by running:

    ```sh
    npm install
    ```

### Running the Application

1.  Start the development server with Parcel by running:

    ```sh
    npx parcel ./src/index.html
    ```

2.  Open the application in your browser by clicking on the server link (usually `http://localhost:1234`) in the terminal.
